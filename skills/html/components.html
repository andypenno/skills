Charts - opt-in (pure CSS / inline SVG, no library)

Theme-aware via currentColor + CSS vars. Each carries an aria-label; gate any animation behind prefers-reduced-motion (already done above).

Stacked bar - proportions via flex-grow

<div class="bar" role="img" aria-label="620 shared, 180 A, 200 B">
  <span class="seg s-green" style="--v:620"></span>
  <span class="seg s-amber" style="--v:180"></span>
  <span class="seg s-red"   style="--v:200"></span>
</div>
/* CSS: .seg{flex:var(--v)} - values are relative, need not sum to 100 */

Donut / progress ring - SVG circle, r=15.915 so circumference=100 ⇒ dasharray reads as %

<svg viewBox="0 0 42 42" class="ring" role="img" aria-label="Coverage 72%">
  <circle class="track" cx="21" cy="21" r="15.915" fill="none" stroke-width="4"/>
  <circle class="fill"  cx="21" cy="21" r="15.915" fill="none" stroke-width="4"
          stroke-dasharray="72 28" stroke-dashoffset="25" stroke-linecap="round"/>
  <text x="21" y="21" dy=".35em" text-anchor="middle" class="label">72%</text>
</svg>
/* dasharray="<pct> <100-pct>"; offset 25 starts the arc at 12 o'clock */

Sparkline - SVG polyline, x=index, y=max−value

<svg class="spark" viewBox="0 0 9 15" preserveAspectRatio="none" role="img" aria-label="Trend">
  <polyline points="0,14 1,15 2,10 ..." fill="none" stroke="currentColor"
            stroke-width="2" vector-effect="non-scaling-stroke"/>
</svg>
